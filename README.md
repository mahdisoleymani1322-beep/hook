# hook — Claude Skill

Generate a complete, algorithm-friendly short-video package for Instagram Reels and TikTok (content style, hook, full production spec) from a single topic. Includes a Narrative Spine branch for animated/character-driven content and a diagnose mode for already-published reels. Persian by default.

## Install
Copy the `hook/` folder into your Claude skills directory (or zip it and upload it as a skill in Claude settings).

## Structure
- `hook/SKILL.md` — router
- `hook/layers/` — per-layer instructions, loaded on demand
- `hook/references/` — hook bank, QC rubric, diagnose, narrative
