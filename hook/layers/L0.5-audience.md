## 🧠 Layer 0.5 — تحلیل مخاطب

**چرا مهم است:** هوک قوی از **درد پنهان** می‌آید، نه درد سطحی. اگر این لایه را رد کنی، هوک‌هایت تکنیکی درست ولی سطحی می‌شوند.

اگر اطلاعات کافی نداری، **استنباط کن و با برچسب `[فرض]` علامت بزن** — نپرس مگر TOPIC واقعاً مبهم باشد.

| بُعد | سؤال کلیدی |
|---|---|
| **مخاطب دقیق** | دقیقاً چه کسی؟ (سن، نقش، موقعیت — نه «همه») |
| **درد سطحی** | چه چیزی را خودش می‌گوید که مشکلش است؟ |
| **درد پنهان** | چه چیزی واقعاً اذیتش می‌کند ولی نمی‌گوید یا نمی‌داند؟ |
| **خواسته سطحی** | چه چیزی را ظاهراً می‌خواهد؟ |
| **خواسته عمیق** | پشت آن خواسته، دنبال چه حسی/جایگاهی است؟ |
| **ممنوعه‌ها** | چه حرف‌هایی را آن‌قدر شنیده که دیگر اثر ندارد؟ |
| **نقطه کور** | چه چیزی را نمی‌فهمد یا اشتباه می‌فهمد؟ |

```
مخاطب دقیق: ...
درد سطحی: ...
درد پنهان: ...          ← منبع اصلی هوک
خواسته سطحی: ...
خواسته عمیق: ...
ممنوعه‌ها (نگو): ...     ← این جمله‌ها را در هوک و کپشن استفاده نکن
نقطه کور: ...           ← منبع اصلی ارزش آموزشی
```

**قوانین سخت‌گیرانه:**
1. **درد پنهان ≠ درد سطحی.** سطحی: «وقت ندارم محتوا بسازم» / پنهان: «می‌ترسم بسازم و کسی نبیند، پس تعللش می‌کنم»
2. **ممنوعه‌ها باید مشخص باشند.** «کلیشه‌ها» ❌ / «"محتوا پادشاه است"، "روزی یک پست بذار"» ✅
3. مخاطب «همه» نیست. «صاحبان کسب‌وکار» خیلی کلی است — بشکافش.
