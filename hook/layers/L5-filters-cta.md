## 🎯 Layer 5 — دروازه نهایی: فیلتر مخاطب

```
آیا این سناریو یکی از این سه را انجام می‌دهد؟
  [ ] دغدغه‌ای را برطرف می‌کند → کدام؟
  [ ] هزینه‌ای را کاهش می‌دهد → کدام؟
  [ ] در زمان صرفه‌جویی می‌کند → چه زمانی؟
اگر هیچ‌کدام → REJECT، برگرد به Layer 0.
```

### 🚫 فیلتر ضد-گورو

روی **هوک، متن گوینده و کپشن** اجرا شود:

| # | چه حذف شود | ممنوع | جایگزین |
|---|---|---|---|
| 1 | لحن گورو | «رازی که زندگیت رو عوض می‌کنه» | «این تنظیم ساده ۴۰٪ زمان صرفه‌جویی می‌کنه» |
| 2 | اغراق | «۱۰۰٪ تضمینی» | عدد یا محدوده‌ی واقعی |
| 3 | ادعای بی‌پشتوانه | «بهترین روش دنیا» | «در تست ما روی ۱۲ پروژه، این بهتر جواب داد» |
| 4 | وعده غیرواقعی | «یک شبه میلیونر شو» | نتیجه واقع‌بینانه با بازه زمانی |
| 5 | کلی‌گویی انگیزشی | «فقط باید بخوای» | یک عمل مشخص و قابل اجرا |
| 6 | **فوریت جعلی** ⭐ | «فقط امروز! آخرین فرصت!» درحالی‌که فردا هم هست | «تا پنج‌شنبه بازه، چون کلاس جمعه شروع می‌شه» |
| 7 | **خودستایی مستقیم** ⭐ | «ما براشون ۵ میلیون ویو گرفتیم» | **قاب کاشف:** «گفتن رفت‌وآمدش زیاده، اومدم ببینم چه خبره» |
| 8 | ممنوعه‌های Layer 0.5 | هر جمله‌ی ثبت‌شده در ممنوعه‌ها | زاویه تازه از Layer 1.5 |

> **قاب کاشف (Discoverer Frame):** وقتی نتیجه‌ای را روایت می‌کنی، خودت را در نقش **کسی که کنجکاو شده** بگذار، نه کسی که مدعی است. همان عدد، از زبان کاشف، باورپذیرتر است و مقاومت مخاطب را فعال نمی‌کند. اجازه بده **اعداد و صدای سوم‌شخص** ادعا کنند، نه خودت.

### 🔒 قفل عدد (Number Lock) ⭐

**هیچ عددی در خروجی نمی‌آید مگر یکی از این سه:**

1. کاربر آن را داده باشد
2. از یک شاهد قابل‌ارجاع آمده باشد (اینسایت، سند، اندازه‌گیری)
3. صریحاً `[فرض]` یا `[جای عدد واقعی]` برچسب خورده باشد

**ساختن عدد باورپذیر ممنوع است — حتی به‌عنوان نمونه.** «۱۸٪ کم‌مس» و «۴۰٪ صرفه‌جویی» اگر از هیچ‌جا نیامده‌اند، نوشته نمی‌شوند؛ به‌جایشان `[درصد واقعی را اینجا بگذار]` می‌آید.

دلیل این قفل: در خودارزیابی، سازنده و داور یکی است و عدد ساختگی از دروازه‌ی اخلاقی رد می‌شود چون «باورپذیر» به‌نظر می‌رسد. این قفل قبل از آن دروازه اجرا می‌شود و قضاوتی نیست — مکانیکی است.

### 🧱 دروازه‌های ساختاری U1–U3 ⭐

سه نقصی که ۲۴ معیار امتیازی نمی‌گیرند. **دروازه‌اند، نه امتیاز** — فِیل هر کدام تحویل را متوقف می‌کند.

#### U1 — وحدت ادعا (شمارش‌پذیر)

ادعاهای **مستقل** بدنه فهرست می‌شوند. ادعای مستقل = گزاره‌ای که اگر حذف شود، بقیه‌ی ویدیو همچنان کامل است.

```
گزارش اجباری:  ادعاهای مستقل: _ عدد  →  [فهرست]     (مجاز: ۱)
```

نمونه‌ی فِیل: «لوله ظرفیت را کم می‌کند» + «تعداد سیم ظرفیت را کم می‌کند» = دو مکانیزم مستقل.
رفع: یکی را به **اصل** و دیگری را به **نمونه‌ی همان اصل** تبدیل کن، یا دومی را حذف و به ویدیوی جدا منتقل کن.

معیار ۱۹ فقط افشای هوک را می‌سنجد، نه وحدت بدنه. این دروازه جای آن خلأ را پر می‌کند.

#### U2 — اجراپذیری شات‌به‌شات (شمارش‌پذیر)

هر ردیف شات‌لیست باید هر سه را داشته باشد: **سوژه‌ی مشخص · اکشن مشخص · قاب مشخص**. ردیفی که نیازمند تفسیر فیلم‌بردار است، مبهم شمرده می‌شود.

```
گزارش اجباری:  ردیف‌های مبهم: _ از _     (مجاز: ۰)
```

نمونه‌ی فِیل: «انگشت روی جدول ضریب کاهش» — کدام جدول، کدام ستون، چه قابی.
معیار ۱۰ این را با پاس/فِیل می‌سنجد و در عمل همیشه پاس می‌شود؛ شمارش ردیف‌های مبهم قابل جعل نیست.

#### U3 — ریسک مالکیت فکری و صحت

```
[ ] جدول، نمودار، عکس یا متن شخص ثالث در قاب نیست
    (بازسازی گرافیکی خودمان مجاز است، نمایش اصل نه)
[ ] لوگو، بسته‌بندی یا نام برند شخص ثالث بدون اجازه در قاب نیست
[ ] موسیقی دارای مجوز است
[ ] هر ارجاع به استاندارد، قانون یا سند با قید [نسخه را تأیید کن] همراه است
[ ] چهره‌ی هیچ فردی بدون رضایت در قاب نیست
```

هیچ‌کدام از این‌ها در ۲۴ معیار یا در فیلتر ضد-گورو پوشش نداشت.

### ⚖️ دروازه‌ی اخلاقی ۵ سؤالی ⭐

📖 شرح کامل در `hook-qc.md` بخش ۸.

```
[ ] ۱. ادامه‌ی محتوا دقیقاً وعده‌ی شروع را تحویل می‌دهد؟
[ ] ۲. عدد یا تجربه‌ی ادعاشده قابل‌اثبات است؟
[ ] ۳. ترس مخاطب را بی‌دلیل تشدید نمی‌کنم؟
[ ] ۴. استثنا یا محدودیت مهمی را پنهان نکرده‌ام؟
[ ] ۵. اگر این جمله درباره‌ی خودم بود، منصفانه می‌دانستمش؟
```

اگر هر کدام فِیل شد → **آن جمله** بازنویسی شود، نه کل سناریو.

## 📞 Layer 5.5 — مهندسی CTA اجرایی

**قانون طلایی:** هر خروجی باید CTA‌ای داشته باشد که به یک **عمل قابل اندازه‌گیری** منجر شود.

### ساختار اجباری — Triple

```
(نوع تعامل، محرک عملی، متن/عمل دقیق)
```

```
✅ نوع: کامنت · محرک: سؤال باز با جواب کوتاه · متن: «شما با ۱ کار می‌کنید یا ۲؟»
❌ «تعامل ارگانیک با مخاطب»  · ❌ «فالو، لایک، کامنت»
```

### نگاشت GOAL → نوع تعامل

| GOAL | اصلی | جانبی | قید |
|---|---|---|---|
| `view` | share | save | — |
| `follow` | follow | comment | — |
| `sale` | direct message | link click | — |
| `cta_engagement` | comment / direct / call | share | — |
| `save` | save | comment | ← محرک ۸ یا ۹ اجباری |
| `share` | share | comment | — |

### ۱۰ محرک عملی

1. **سؤال باز با جواب کوتاه** — «کدومو انتخاب می‌کنی؟ ۱ یا ۲؟»
2. **تست/چالش زمان‌دار** — «۲۴ ساعت امتحان کن، نتیجه رو کامنت بذار»
3. **درخواست تجربه شخصی** — «تجربه‌ات از X چی بوده؟»
4. **FOMO محدود** — «فقط ۱۰ نفر — دایرکت بده»
5. **راه‌حل شخصی‌سازی‌شده** — «وضعیتت رو بگو، جواب مخصوص خودت رو می‌دم»
6. **بحث/موضع‌گیری** — «موافقی یا نه؟ چرا؟»
7. **لایه پنهان (Loop closing)** — «یه چیز مهم دیگه هست — کامنت بذار «۱»»
8. ⭐ **ارزش مرجع (مخصوص `save`)** — «این سه عدد رو موقع خرید بپرس» / «این چک‌لیست رو موقع نصب باز کن». سیو وقتی اتفاق می‌افتد که مخاطب **لحظه‌ی آینده‌ای** را تصور کند که به این محتوا برمی‌گردد. CTA باید آن لحظه را نام ببرد.
9. ⭐ **بسته‌نشدن حلقه‌ی عملی (مخصوص `save`)** — محتوا یک ابزار/گام/عدد قابل‌اجرا می‌دهد که همان لحظه قابل انجام نیست. سیو می‌شود چون باید بعداً اجرا شود.
10. ⭐ **کلمه‌ی کلیدی کامنت** — «کلمه‌ی "پروژه" رو کامنت کن تا برات بفرستم». قابل اتوماسیون با ابزار دایرکت، قابل شمارش دقیق، و کامنت‌های یکسان سیگنال تعامل می‌سازند. **شرط:** چیزی که وعده می‌دهی واقعاً باید فرستاده شود، وگرنه فقط اعتماد سوزانده‌ای.

```
### CTA اجرایی
نوع تعامل هدف: ... · محرک عملی: [#شماره] ...
متن/عمل دقیق: «...» · جایگاه: ثانیه ... تا ...
دلیل انتخاب: ...
```
