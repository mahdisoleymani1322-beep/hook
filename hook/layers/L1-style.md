## 🎬 Layer 1 — تشخیص سبک محتوا

از این ۲۰ سبک، **یک سبک اصلی + یک سبک پشتیبان** انتخاب کن.

| # | سبک | مناسب برای |
|---|---|---|
| 1 | مستقیم (Talking Head) | آموزشی، خدماتی، برند شخصی |
| 2 | ولاگ | برند شخصی، روزمرگی، پشت‌صحنه |
| 3 | پرسش و پاسخ | آموزشی، خدماتی، اعتمادسازی |
| 4 | کلیپ پادکست | برند شخصی، آموزشی، اعتبار |
| 5 | آموزشی مرحله‌به‌مرحله | آموزشی، خدماتی |
| 6 | روایت داستانی | برند شخصی، اعتمادسازی، فروش |
| 7 | واکنشی | سرگرمی، ترند |
| 8 | مصاحبه | آموزشی، برند شخصی |
| 9 | پشت صحنه (BTS) | فروشگاهی، خدماتی، برند شخصی |
| 10 | کیس‌استادی | خدماتی، B2B، فروش |
| 11 | نمایش محصول | فروشگاهی |
| 12 | کمدی/تئاتری (Skit) | سرگرمی، برند شخصی |
| 13 | پرده سبز | آموزشی، واکنشی، ترند |
| 14 | مونتاژ صداگذاری | آموزشی، فروشگاهی |
| 15 | تایم‌لپس فرآیند | خدماتی، فروشگاهی، هنری |
| 16 | مقایسه‌ای (A vs B / Before-After) | فروشگاهی، آموزشی |
| 17 | رتبه‌بندی/تیرلیست | همه حوزه‌ها |
| 18 | لیستی (Top 5, Top 10) | آموزشی، فروشگاهی |
| 19 | مستندی | آموزشی، برند شخصی |
| 20 | ترند/قالب | همه — سریع ویو می‌گیرد |

**سبک تابع سه چیز است: GOAL، NICHE، و ماهیت ذاتی موضوع.** ماهیت موضوع اول بررسی می‌شود:

```
ماهیت ذاتی موضوع (اولویت اول):
  موضوع دو چیز را مقابل هم می‌گذارد
  (این/آن، قبل/بعد، واقعی/تقلبی، گران/ارزان)   → مقایسه‌ای (16) + سبک دوم از جدول زیر
  موضوع یک فرایند فیزیکی قابل‌مشاهده است        → تایم‌لپس (15) یا نمایش محصول (11)
  موضوع یک نتیجه‌ی واقعی مشتری است              → کیس‌استادی (10) + پشت صحنه (9)
  هیچ‌کدام                                       → فقط از جدول زیر

جدول GOAL × NICHE:
  sale    + خدماتی/B2B   → کیس‌استادی + پشت صحنه
  sale    + فروشگاهی     → نمایش محصول + مقایسه‌ای
  follow  + آموزشی       → آموزشی مرحله‌به‌مرحله + لیستی
  follow  + برند شخصی    → روایت داستانی + ولاگ
  follow  + خدماتی/B2B   → پرسش و پاسخ + روایت داستانی
  follow  + فروشگاهی     → پشت صحنه + مقایسه‌ای
  save                   → آموزشی مرحله‌به‌مرحله + لیستی
  share / view           → ترند/قالب + رتبه‌بندی
  NICHE == سرگرمی        → کمدی/تئاتری + واکنشی
  DEFAULT                → مستقیم + مقایسه‌ای
```

**قانون:** اگر ماهیت موضوع با جدول GOAL×NICHE اختلاف داشت، **ماهیت برنده است** و جدول سبک دوم را می‌دهد. تخطی از جدول با ذکر دلیل مجاز است؛ تخطی بی‌دلیل نه.

**قانون شرطی `narrator_only`:** سبک منتخب باید از این ۵ باشد: روایت داستانی (6) · مونتاژ صداگذاری (14) · تایم‌لپس فرآیند (15) · لیستی (18) · مستندی (19). جایگزینی: مستقیم → مونتاژ صداگذاری · آموزشی قدم‌به‌قدم → تایم‌لپس · نمایش محصول → مونتاژ صداگذاری · کمدی → روایت داستانی.

**خروجی:** «سبک اصلی: X · سبک پشتیبان: Y · حالت حضور: ... · ماهیت موضوع: ... · دلیل: ...»

> **Layer 3 حذف شده است.** در نسخه‌های قبلی یک لایه‌ی جدا برای «نگاشت به مدل محتوا» وجود داشت که چیزی جز بازگویی GOAL و سبک تولید نمی‌کرد. کارکردش در همین لایه ادغام شد. شماره‌ی ۳ عمداً خالی مانده تا شماره‌گذاری بقیه‌ی لایه‌ها نشکند.
