## 📊 Layer 8 — تست و سنجش ⭐

خودکفا است — برای اجرای این لایه نیازی به خواندن فایل مرجع نیست.

هر خروجی `production` با این دو بخش بسته می‌شود:

**۱. برنامه‌ی تست A/B**
۳ هوک جایگزین = ۳ نسخه‌ی تست، از **۳ زاویه‌ی متفاوت** (نه سه بازنویسی جمله‌ای یک زاویه). متغیرهای ثابت: بدنه · طول · CTA · ساعت انتشار. معیار برنده اعلام می‌شود.

**۲. متریک تصمیم‌گیر**

| GOAL | متریک تصمیم‌گیر |
|---|---|
| `view` | ویو ۲۴ ساعت اول نسبت به تعداد فالوور |
| `follow` | نرخ فالو از غیرفالوور |
| `sale` | کلیک لینک / دایرکت خرید |
| `cta_engagement` | تعداد کامنت/دایرکت قابل ردیابی |
| `save` | نرخ سیو نسبت به ویو |
| `share` | نرخ شیر نسبت به ویو |

**اصل:** هر بار فقط **یک متغیر** عوض می‌شود. وگرنه نمی‌فهمی کدام تغییر اثر گذاشت.

📖 پروتکل کامل تست، متریک‌های تکمیلی و آرشیو برنده‌ها: `references/diagnose.md` بخش ۲–۴ — **فقط اگر کاربر برنامه‌ی تست تفصیلی خواست**.

## 🔐 Layer 9 — دروازه‌ی پیش‌تحویل

**آخرین مرحله قبل از نمایش هر خروجی به کاربر.** ۱۷ بند. هر بند فِیل شود، خروجی نمایش داده نمی‌شود و به لایه‌ی نام‌برده برمی‌گردد.

```
[ ] ۱  درخت بارگذاری اجرا شده و MODE و NARRATIVE_MODE اعلام شده‌اند
[ ] ۲  هر ۱۶ مرحله‌ی نقشه‌ی اجرا خروجی قطعی‌اش را تولید کرده — هیچ مرحله‌ای رد نشده
[ ] ۳  هر ۹ معیار گروه S مقدار عددی دارند، نه تیک          → Layer 7
[ ] ۴  قفل عدد: هیچ عددی بدون منبع یا بدون براکت نیست      → Layer 5
[ ] ۵  زاویه‌ی منتخب در بیت اول اجرا شده طبق جدول سازگاری     → قفل زاویه، Layer 4.5
[ ] ۶  ماتریس اعمال معیارها لحاظ شده؛ سقف و آستانه مطابق حالت
[ ] ۷  بسته‌ی تولید هر ۷ بخش را دارد؛ هیچ بخشی ناقص نیست    → Layer 6

       «Layer» در متن قابل مشاهده نیست
```
