## 📄 Layer 6 — قالب خروجی نهایی

### 📏 طول بر اساس ژانر ⭐

طول درست تابع **دمای مخاطب** است، نه یک عدد ثابت. مخاطب سرد (اسکرول) تحمل کم دارد؛ مخاطب گرم (کسی که دنبال همین چیز می‌گردد) تا دو برابر می‌ماند.

**هر هفت چارچوب Layer 4.5 اینجا ردیف دارند — هیچ چارچوبی بدون بازه نمی‌ماند.**

| چارچوب منتخب | بازه‌ی سالم | پیش‌فرض | دمای مخاطب |
|---|---|---|---|
| **In Medias Res** (+ ترند / رتبه‌بندی / سرگرمی) | ۱۰–۲۵s | ۱۵s | سرد |
| **Contrast** | ۲۰–۴۰s | ۳۰s | سرد |
| **PAS** | ۲۰–۴۵s | ۳۰s | سرد تا نیم‌گرم |
| **Practical Framework** (آموزشی / لیستی / چک‌لیست) | ۲۵–۵۰s | ۳۵s | نیم‌گرم |
| **Hero's Journey** | ۳۰–۶۰s | ۴۵s | نیم‌گرم |
| **Narrative Spine** — `narrative_story` | ۲۰–۴۵s | ۳۰s | سرد |
| **Narrative Spine** — `narrative_ad` | ۳۰–۶۰s | ۴۰s | نیم‌گرم |
| **Case Spine** ⭐ | **۶۰–۱۲۰s** | **۹۰s** | گرم و نیت‌دار |
| مستندی / روایت عمیق برند (سبک، نه چارچوب) | ۶۰–۱۲۰s | ۸۰s | گرم |

**قوانین:**
- خارج از بازه‌ی ژانر → **بپرس**، خودسرانه کوتاه یا بلند نکن
- هر ویدیوی > ۴۵ ثانیه: لوپ بازگشتی (گام 4.7.4) پیش‌فرض است + تعداد Re-Hook طبق جدول Layer 4.7.2
- طول بیشتر **مجوز کندی نیست** — کادنس ~۳ ثانیه و فاصله‌ی پاداش ≤ ۷ ثانیه در هر طولی ثابت‌اند

### حالت کاری و حالت نمایش (دو محور جدا)

**محور اول — `MODE` (چه کاری انجام می‌شود):**

| MODE | ورودی | خروجی | لایه‌های اجراشده |
|---|---|---|---|
| `create` ⭐ پیش‌فرض | موضوع خام | سناریوی نو | ۰ تا ۸ |
| `diagnose` | محتوای منتشرشده + آمار | تشخیص + اصلاح تک‌متغیره | هیچ لایه‌ای؛ فقط `diagnose.md` بخش ۱ و ۳ |

**محور دوم — حالت نمایش (فقط وقتی `MODE == create`):**

| نمایش | چه دیده می‌شود |
|---|---|
| **`production`** ⭐ پیش‌فرض | بسته تولید ۷-جزئی + هوک منتخب + ۳ جایگزین + برنامه‌ی تست |
| **`full`** | همه‌ی بالا، به‌علاوه‌ی تمام لایه‌های تحلیلی و جدول امتیازدهی |

**فعال‌سازی `full`:** «تحلیل رو نشون بده»، «مراحل رو بگو»، «چرا این زاویه؟»، «full».

**قوانین سخت‌گیرانه:**
- لایه‌های تحلیلی **هرگز رد نمی‌شوند** — فقط پنهان می‌شوند
- در `production` هیچ عنوان لایه‌ای نیاید — کاربر نباید کلمه «Layer» ببیند
- اگر پارامتری `[فرض]` بود، یک خط در **انتها**: «فرض‌ها: ...»

**فریم آخر:** ... (اگر لوپ است، چه چیزی با فریم صفر یکی می‌شود)
**فرض‌ها:** ...

**نکته:** CTA کپشن باید همان **نوع تعامل + محرک** Layer 5.5 را بازتاب دهد، نه چیز دیگری.

### دلتای قالب Case Spine

وقتی چارچوب منتخب Case Spine است، این چهار مورد **به قالب عمومی اضافه** می‌شوند — قالب جایگزین نمی‌شود:

```markdown
## ۰. اعتبار کیس
- دروازه‌ی داده: D1 ✓ [چه عددی] · D2 ✓ [چه شاهدی] · D3 ✓ [چه صدایی] · D4 ✓
- سهم زمانی حرف‌زدن از خود: __٪ (سقف ٪۲۰ — قید C3)

## ۲.۱ بودجه‌ی بیت‌ها
Result Tease __s · Hard Proof __s · Journey __s · Client's World __s
· Third-Party __s · CTA+Loop __s
جایگاه اثبات خام: ثانیه __ · جایگاه صدای سوم‌شخص: ثانیه __
```

و در ستون آخر شات‌لیست، نام بیت Case Spine نوشته می‌شود (به‌جای «پاداش/Re-Hook» که به ستون جدا می‌رود).

تأیید C1–C4 در خط گزارش Layer 9 می‌آید: `C:۴/۴`.

### قالب `full` (فقط در صورت درخواست صریح)

همان قالب `production` است، با این بخش‌ها **قبل از** آن:

```markdown
## ورودی‌ها
موضوع: ... · حوزه: ... · هدف: ... (دلیل: ...) · حضور: ... · چارچوب: ...

## تحلیل مخاطب
مخاطب دقیق / درد سطحی / **درد پنهان** / خواسته سطحی / خواسته عمیق / ممنوعه‌ها / نقطه کور

## زاویه
زاویه‌های اشباع‌شده: ۱... ۲... ۳...
۴ زاویه تازه: درد / تضاد / راز / نتیجه
**زاویه منتخب:** ... — دلیل: ...
Feature: ... → Outcome: ... → پل: ...

## ۱۰ هوک + جدول QC

| # | هوک | مدل (دسته) | وضوح | ارتباط | مشخص | تنش | باور | کوتاه | جمع |
|---|---|---|---|---|---|---|---|---|---|
| 1 | «...» | ... | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 6 |

هوک‌های بصری: #۱ (تکنیک ...) ... · #۲ (تکنیک ...) ...
**هوک منتخب:** «...» — امتیاز QC: ... /۶ · افشا: ...٪

## معماری روایت
چارچوب: ... · نقاط تنش: ثانیه ... / ... / ... · بیشترین فاصله: ...s (≤۱۰)
مرحله ۱ / ۲ / ۳ — طبق قالب هر مرحله

## معماری ریتنشن
جدول Micro-Reward · Re-Hookها · کادنس · لنگر ثابت/محیط متغیر · نوع پایان

## دروازه‌ها
فیلتر مخاطب: [x] ... · ضد-گورو: ۸ ردیف · اخلاقی: ۵ سؤال
(اگر Case Spine: C1 C2 C3 C4)

## امتیازدهی Layer 7
جدول ۲۴ معیاری با پاس/فِیل + جمع + تصمیم (تحویل / بازنویسی / شروع مجدد)
```

سپس بسته تولید ۷-جزئی عیناً مثل حالت `production`.
