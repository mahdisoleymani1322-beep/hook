### 4.7.1 — زنجیره‌ی Micro-Reward

ویدیوی موفق ارزشش را فقط برای یک پاداش بزرگ در انتها نگه نمی‌دارد.

هر Micro-Reward یکی از این‌هاست: پاسخ به یک سؤال کوچک · عدد/نتیجه‌ی ملموس · یک «آها»ی کوچک · تصویر رضایت‌بخش · قدم عملی قابل‌اجرا

- **قانون فاصله — مقیاس‌پذیر با طول:**

| طول ویدیو | بیشترین فاصله‌ی مجاز |
|---|---|
| ≤ ۳۰s | ۵s |
| ۳۱–۴۵s | ۷s |
| ۴۶–۷۰s | ۸s |
| > ۷۰s | ۱۰s |

> **تنش شناخته‌شده — بیت‌های گذار.** در چارچوب‌های بیت‌محور (Narrative Spine، Case Spine) بیت‌های `Turn` و `Journey/BTS` ذاتاً دره‌ی پاداش می‌سازند، چون کارشان گذار است نه تحویل. **قاعده‌ی اجباری:** هر بیت گذار که بیش از ۵ ثانیه طول می‌کشد، باید **یک Micro-Reward داخلی** داشته باشد — یک تغییر بصری که خودش یک جواب کوچک است. بدون آن، قید فاصله در ویدیوهای بالای ۴۵ ثانیه قطعاً می‌شکند.
- **قانون زنجیره:** هر پاداش باید سؤال بعدی را باز کند

```
Micro-Reward → سؤال جدید → Micro-Reward → سؤال جدید → ... → Payoff نهایی   ✅
انتظار طولانی ← ← ← ← Payoff بزرگ در انتها                                  ❌
```

| ثانیه | پاداش کوچک | سؤالی که باز می‌کند |
|---|---|---|
| ۰-۳ | ... | ... |

**مثال:**
```
۰-۳:   «چرا املت خونگی مثل کافه‌ها نمی‌شه؟»    → مگه چیکار می‌کنن؟
۴-۸:   «تنها فرقش دمای تابه‌ست»                 → چه دمایی؟
۹-۱۴:  کلوزآپ کره‌ی کف‌کرده                     → از کجا بفهمم آماده‌ست؟
۱۵-۲۰: نشانه‌ی بصری آمادگی                       → بعدش چی؟
۲۱-۲۶: املت نهایی + برش                         → پاداش نهایی + CTA
```

### 4.7.2 — Re-Hook میانی

| طول ویدیو | Re-Hook اجباری |
|---|---|
| ≤ ۲۰ ثانیه | ۰ (اختیاری) |
| ۲۱–۴۰ ثانیه | حداقل ۱ |
| ۴۱–۶۰ ثانیه | حداقل ۲ |
| > ۶۰ ثانیه | هر ~۲۰ ثانیه یکی |

**Re-Hook چیست:** نقطه‌ی **ریست کامل توجه** — انگار یک ریلز دوم وسط ریلز اول شروع شده.

**ابزارها:** شماره‌گذاری/فصل‌بندی · **جمله‌ی ضدانتظار (قوی‌ترین)** · تغییر شدید بصری · سؤال جدید مستقل · **تعویض راوی** ⭐ (سپردن روایت به یک نفر دوم — صدای تازه + چهره‌ی تازه همزمان، قوی‌ترین ریست در ویدیوهای بلندتر از ۴۵ ثانیه)

**قانون:** Re-Hook باید **هم‌زمان** تغییر بصری و محرک متنی/کلامی داشته باشد. صرفِ cut کافی نیست.

### 4.7.3 — کادنس برش + قفل لنگر

**تفاوت با قانون ۱۰ ثانیه:** آن درباره‌ی **تنش روایی** است، این درباره‌ی **برش بصری**. دو سطح متفاوت.

**کادنس:** میانگین هر **~۳ ثانیه** یک تغییر بصری محسوس (بازه‌ی سالم ۲–۴؛ هیچ نمای پیوسته‌ای > ~۶ ثانیه).

> **بیت ≠ شات:** یک بیت ۱۵ ثانیه‌ای از چند شات ≤ ۶ ثانیه تشکیل می‌شود.

**قفل «لنگر ثابت + محیط متغیر»:**
- **ثبات شناختی:** یک لنگر ثابت در کل ویدیو (همان شخصیت، محصول محوری، دست/راوی)
- **تازگی بصری:** محیط، زاویه و عناصر پیرامون مدام عوض می‌شوند

```
لنگر ثابت: [چیست و در چند درصد شات‌ها حاضر است]
محیط/عناصر متغیر: [۴-۶ مورد]
```

**متن روی تصویر = لایه‌ی روایت مستقل، نه زیرنویس.** اگر صدا خاموش شود، خواندن پی‌درپی خطوط متن باید بخش بزرگی از داستان را منتقل کند.

### 4.7.4 — طراحی پایان: لوپ، فرود یا تعلیق ⭐

**قانون:** هر ویدیو باید **یکی از این سه نوع پایان** را آگاهانه انتخاب کند. «تمام شدن» نوع پایان نیست.

| نوع پایان | چطور کار می‌کند | کِی انتخاب کن |
|---|---|---|
| **لوپ بازگشتی (Bookend)** | فریم/جمله‌ی آخر **همان فریم یا جمله‌ی ثانیه‌ی صفر** است، طوری که ویدیو بی‌درز دوباره شروع شود | Case Spine · روایت · هر جا بازپخش ارزش دارد |
| **فرود بسته (Payoff Landing)** | مسیر جمع می‌شود، جواب تحویل می‌شود، CTA فرود می‌آید | آموزشی · چک‌لیستی · `GOAL = save` |
| **تعلیق ادامه‌دار (Open Loop)** | یک لایه‌ی باقی‌مانده که فقط با کامنت/دایرکت باز می‌شود | `GOAL = cta_engagement` |

#### لوپ بازگشتی — اجرا

اثرش مستقیم روی **بازپخش** و **میانگین تماشای بالای ٪۱۰۰** است؛ الگوریتم هر دو را می‌بیند.

سه راه اجرا:
1. **لوپ تصویری:** فریم آخر = فریم اول (همان قاب، همان زاویه)
2. **لوپ کلامی:** جمله‌ی آخر = جمله‌ی اول، ولی حالا معنایش عوض شده چون مخاطب داستان را می‌داند
3. **لوپ سؤالی:** پایان همان سؤالی را می‌پرسد که ویدیو با آن شروع شد

```
نوع پایان منتخب: ...
اجرای دقیق فریم/جمله‌ی آخر: ...
اگر لوپ است — چه چیزی با فریم صفر یکی می‌شود: ...
چرا این نوع پایان با GOAL همخوان است: ...
```

**قانون:** در Case Spine و در هر ویدیوی بلندتر از ۴۵ ثانیه، **لوپ بازگشتی پیش‌فرض است** مگر دلیل صریحی خلافش باشد.
